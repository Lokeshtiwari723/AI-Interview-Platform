# AI Interview Platform

An AI-powered mock interview platform designed to help candidates prepare for technical interviews through voice and video interviews, answer evaluation, and personalized feedback.

## Overview

AI Interview Platform provides an interactive environment where users can practice interview questions based on their selected technical role and experience level.

The goal is to help candidates identify their strengths, understand their weaknesses, and improve their interview performance.

## Features

- **Multiple Interview Roles** – Practice for different technical roles such as Frontend, Backend, Full Stack, and Data Analyst.
- **Difficulty Levels** – Choose Fresher, Medium, or Advanced.
- **Voice Interviews** – Listen to interview questions and answer using your voice.
- **Video Interviews** – Practice through a video interview interface.
- **Text Answers** – Type answers instead of speaking.
- **AI-Based Evaluation** – Receive scores and feedback on your answers.
- **Performance Reports** – Review strengths, weaknesses, and areas for improvement.
- **Interview History** – Save and revisit previous interview sessions.
- **Guest Mode** – Try up to 10 questions without creating an account.

## Tech Stack

- **Frontend:** React, JavaScript, HTML, CSS
- **Backend:** Python, FastAPI
- **Database & Authentication:** Supabase
- **Local AI:** Ollama

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Lokeshtiwari723/AI-Interview-Platform.git
```

### 2. Open the Project

```bash
cd AI-Interview-Platform
```

### 3. Setup Frontend

```bash
cd frontend
npm install
npm run dev
```

### 4. Setup Backend

Open another terminal and follow the backend dependency and environment configuration in the `backend` folder.

### 5. Configure Environment Variables

Configure your Supabase credentials and other required environment variables locally.

Do not upload private API keys, passwords, or secret credentials to GitHub.
